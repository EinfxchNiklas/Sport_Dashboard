# Beitragen zum Projekt

Vielen Dank für dein Interesse an einer Mitarbeit!

Dieses Projekt erlaubt externe Beiträge ausschließlich über Pull Requests.

---

## Grundprinzip

- Das Projekt gehört ausschließlich dem Repository Owner
- Alle Änderungen werden zentral kontrolliert
- Beiträge werden nur nach Prüfung übernommen

---

## Regeln für Beiträge

- Kein direkter Push auf das Haupt-Repository
- Änderungen nur über Fork + Pull Request
- Jeder PR kann ohne Begründung abgelehnt werden
- Der Repository Owner entscheidet final über alle Änderungen

---

1. Repository forken
2. Einen neuen Branch erstellen:
